# Assets and licences

Every outside asset used by the game, with its source and licence. Everything else (terrain colours, road
texture, car, buildings, trees, sky) is generated by code in this repository.

| Asset | Used for | Source | Licence |
|---|---|---|---|
| Terrain elevation tiles ("Terrarium" format) | The shape of the land | Mapzen Terrain Tiles on AWS Open Data (`elevation-tiles-prod`), built from SRTM and other public datasets | Free to use with attribution; see the note below |
| Ground, road and wall textures: `rock_face_03`, `worn_rock_natural_01`, `dry_ground_01`, `asphalt_02`, `large_sandstone_blocks_01` (colour and normal maps, 1K) | Terrain detail, the road, stone walls | Poly Haven (polyhaven.com), stored in `src/assets/textures/` | CC0: free for any use, no credit required |
| Stone and plaster textures for the Unity walk: `yellow_stone_wall` (city walls), `sandstone_blocks_08` and `white_sandstone_blocks_02` (houses, gates), `white_plaster_rough_01` (plastered houses), `rock_tile_floor` (lanes, courtyard, platform), `marble_01` (the Dome of the Rock's lower walls); colour and normal maps, 1K, downloaded 16 November 2026 | Phase E3 realism | Poly Haven, stored in `unity/Assets/Rihla/Textures/PolyHaven/` | CC0 |
| Sky for the Unity walk: `kloofendal_38d_partly_cloudy_puresky` (HDRI, 2K, `.hdr`), downloaded 19 November 2026 | R4: the photographed morning sky with clouds over the walk | Poly Haven, stored in `unity/Assets/Rihla/Textures/Sky/` | CC0 |
| Weathering noise and leaf textures (`unity/Assets/Rihla/Textures/Generated/`) | R4: weathered stone, leaf cards for trees and plants | Generated by code in `RihlaWalkLife.cs` | Part of this project |
| Weathered stone shader (`unity/Assets/Rihla/Shaders/`) | R4: weathering on walls and paving | Generated from URP 17's Lit shader, changed in its forward pass | Unity Companion License (URP) |
| Natural Earth: 1:50m coastline and rivers, 1:10m lakes (Dead Sea, Sea of Galilee), downloaded 19 November 2026 from the `natural-earth-vector` repository, simplified and stored in `content/storybook.json` | The maps in Jiddo's storybook (coasts, rivers and lakes; no borders) | naturalearthdata.com | Public domain |
| Room textures for the opening (`unity/Assets/Rihla/Built/Home/`): cement tiles, rug, majlis cloth, the evening sky in the window | C1a: Jiddo's house | Generated by code in `RihlaHomeBuilder.cs` (invented patterns) | Part of this project |
| The picture on the wall in Jiddo's house; its plaster walls use Poly Haven's `white_plaster_rough_01` (listed above) | C1a: a framed view of the Dome of the Rock | This game's own screenshot `docs/screenshots/r4-dome-today.png` | Part of this project |
| Amiri typeface | Arabic and Latin text | `@fontsource/amiri` (the Amiri Project); for Unity its Arabic and Latin web fonts are merged into `unity/Assets/Rihla/Fonts/Amiri-Regular.ttf` and `Amiri-Bold.ttf`, with the licence beside them | SIL Open Font License 1.1 |
| three.js | Rendering, sky shader | npm `three` | MIT |
| Rapier | Physics | npm `@dimforge/rapier3d-compat` | Apache 2.0 |
| Unity 6 and its packages (URP, Input System, Pipeline) | The Unity version of the game | Unity Technologies | Unity Personal licence and Unity Companion License |
| OpenStreetMap data (streets, walls, gates, building outlines of the Old City's north-east and al-Masjid al-Aqsa) | The E2 walk at true scale (`tools/data/osm-*.json` via `tools/build-walk.ts`) | Overpass API exports, 16 November 2026 | ODbL 1.0: credit "© OpenStreetMap contributors" in the game's credits; the derived data is shared under the same licence |
| Cesium for Unity 1.26.1 | Streaming the 3D map in "Al-Quds today" | CesiumGS, registry `unity.pkg.cesium.com` | Apache 2.0 |
| Google Photorealistic 3D Tiles (Cesium ion asset 2275207) | The present-day city in "Al-Quds today" | Google Maps Platform, served through the owner's free Cesium ion account | Streamed only, never stored or shipped; Google and Cesium credits must stay on screen (they do); the free Cesium ion tier is non-commercial |

**Attribution to show in the game's credits before release:** the terrain tiles require crediting their
underlying sources (among them NASA SRTM and other national datasets). The exact wording is listed in
the Mapzen Terrain Tiles attribution notice and must be copied into the credits screen in Phase 7.
